# 话匣子 v2.0.1

这是按开源无签名发布标准构建的 Windows x64 版本，官方附件以 EXE、便携 ZIP 和 `SHA256SUMS.txt` 为准；安装包仅在构建机具备 Inno Setup 6.7.3+ 时作为可选附件提供。

## 本次修复

- 无痕模式启动时不再恢复旧草稿，并会清除已有草稿。
- “历史保留天数”现在会实际清理到期的正常历史；回收站仍按其独立生命周期处理。
- 修复 GitHub Actions 依赖审计脚本，并增加标签构建与发布制品校验。
- 发布附件新增 `SHA256SUMS.txt`。

## 下载与安全提示

本项目没有商业代码签名证书，因此 EXE 和安装包未签名。Windows 可能显示“未知发布者”或 SmartScreen 提示；这是无签名开源软件的预期行为，不代表文件一定有恶意。请只从本项目官方 GitHub Release 下载，并用 `SHA256SUMS.txt` 核对文件。

发布源码以 `v2.0.1` 标签为准。CI 必须通过后才创建该标签和 Release；所有附件均由该标签的源码构建。

## 隐私说明

- API Key 由用户自行提供，使用 Windows DPAPI 绑定当前 Windows 用户加密保存，不提交到仓库或发布包。
- 正常模式下，草稿与历史内容保存在本机，历史数据库内容本身不额外加密。
- 无痕模式不保存草稿或历史。
- 卸载应用默认保留用户数据；需要彻底清除时，请按隐私文档中的路径手动删除。
