# 智能编排与质量保障

话匣子将模型调用封装为受控工作流，而不是直接转发文本。规划器提取场景、风险和事实锚点；Skill 路由器选择最多三个兼容策略；上下文管线按固定层级组装请求；工作流负责生成、解析和结果状态。

## 质量门禁

- 校验人物、数字、日期、否定关系、条件和不确定程度。
- 结构化响应优先使用 Provider Schema，否则使用本地解析器。
- 格式或表达质量不足时最多进行一次定向修复。
- 事实风险、空响应或协议错误不会被标记为成功。
- 失败返回可解释状态，不进入归档。

## 个性化边界

个性化只影响语气、格式和表达习惯；不得改变事实、权限、拒答边界或用户本轮要求。学习依据为用户显式操作形成的结构化统计，不保存“模型稿—用户稿”样本文本。
