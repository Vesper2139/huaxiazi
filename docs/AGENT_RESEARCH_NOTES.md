# Agent 架构研究依据

本项目的设计取成熟研究中的“可验证边界”，而不是直接复制某个框架：

- [ReAct (Yao et al., 2023)](https://arxiv.org/abs/2210.03629) 将推理轨迹与动作交错，使外部观察可以修正计划。本项目对应为有限步数的 Autonomous Harness、工具输出清洗和 trace 审计；不把内部思维链暴露给用户。
- [LoCoMo (ACL 2024)](https://aclanthology.org/2024.acl-long.747/) 评估跨长对话的事实、时间、多跳和多模态记忆。本项目对应 Session/Preference/Profile/Sensitive 分层、事实锚点门禁和冻结测试集；不把“记住了”简化成向量命中率。
- [Mem0](https://arxiv.org/abs/2504.19413) 采用用户、会话和 Agent 状态等多级记忆，并强调生产部署指标。本项目保留其分层思想，但增加用户同意、过期、敏感级别和脱敏要求。
- 混合检索采用词法精确匹配与可插拔稠密评分的组合；检索结果通过 reference-only 信任边界进入上下文，避免知识片段获得系统或工具权限。

## 研究到实现的约束

研究论文的离线指标不能直接等价于本产品质量。发布前必须同时检查安全通过率、事实锚点保留率、约束稳定性、工具副作用和上下文预算；真实模型、Provider 和用户授权数据缺失时，结论只能标记为“策略层已实现”。
