# 话匣子 2.0.0 公开发布与验收摘要

发布日期：2026-08-28  
技术标识：Huaxiazi  
目标平台：Windows 10/11 x64

## 发布范围

本次公开仓库只包含可复现的源码、必要的开放许可 Skill 快照、构建脚本、设计规范和三份交付物：

- `release/Huaxiazi.exe`
- `release/Huaxiazi-Portable.zip`
- `release/Huaxiazi-Setup.exe`

本地配置、DPAPI 密钥、历史正文、日志、临时验收 HTML、构建缓存和调试符号均不纳入仓库。

## 本次校准内容

- 设置页按用户任务重新组织，模型配置、表达能力和历史数据的边界清晰。
- 表达润色与提示词优化共用事实保真与输出清理流程，默认只返回一份可直接使用的结果。
- 供应商配置支持推荐模型与可编辑 Model ID；连接测试失败时不会伪报成功。
- 悬浮精灵状态与生成工作流同步，追问、处理中和完成状态使用不同反馈。
- 调整输入框内外边距、窄窗口布局和滚动区域边界，避免文字遮挡、按钮覆盖和滚动条重叠。

## 验证记录

- Release 构建：无编译错误、无警告。
- 产品设置、快捷键、工作区连续性和表达能力相关测试：均通过。
- 安全回归覆盖 DPAPI、密钥变更、更新包校验、皮肤包路径校验和诊断脱敏。
- 无头环境运行完整 WPF 测试时，Windows `HwndSubclass` 宿主可能在测试收尾阶段触发系统级 FailFast；该环境限制不代表发布程序运行时错误，CI/真实桌面会话应单独执行完整 WPF 验证。

## 隐私边界

话匣子采用用户自带 API Key（BYOK）模式。只有用户主动发起生成时，正文及用户明确填写的背景才会发送给所选模型服务商；项目不提供账号、代理、遥测、云同步、知识库或模型训练服务。

## 兼容说明

2.0.0 采用全新的 Huaxiazi 工程与数据目录，不读取旧版本配置、旧 Skill 元数据或旧更新清单。旧目录不会被程序自动删除，用户可在确认后自行处理。
