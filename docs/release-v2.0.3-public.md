# 话匣子 v2.0.3

这是按开源无签名发布标准构建的澄清状态修复版本。

## 本次修复

- 修复开始新输入任务后仍携带上一轮澄清原文、问题或回答的问题。
- 保留澄清提交发生网络失败时的回答与原文上下文，支持安全重试。
- 增加“未提交澄清后切换新输入”的回归测试，避免旧回答进入下一次模型请求。

## 下载与校验

官方附件包括直接运行版 EXE、便携 ZIP 和 `SHA256SUMS.txt`；安装包仅在构建环境具备兼容的 Inno Setup 时提供。请只从本仓库 Release 下载，并按校验文件核对 SHA-256。

本项目没有商业代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。该提示是无签名开源软件的预期行为，不代表文件一定有恶意。

发布源码以 `v2.0.3` 标签为准，所有附件均由该标签对应源码构建。
