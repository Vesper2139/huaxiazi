# 话匣子 v2.0.2

这是按开源无签名发布标准构建的 Windows x64 补丁版本。

## 本次修复

- 修复连续润色时仍可能提交上一条原文的问题。用户覆盖结果并再次点击润色后，当前文本会作为新的输入任务处理。
- 优化攻击性与暴力表达的降级策略：保留不满、拒绝或边界含义，不再把负面态度反转为夸奖或亲昵表达。
- 增加连续润色与攻击性语义反转回归测试。

## 下载与校验

官方附件包括直接运行版 EXE、便携 ZIP 和 `SHA256SUMS.txt`；安装包仅在构建环境具备兼容的 Inno Setup 时提供。请只从本仓库 Release 下载，并按校验文件核对 SHA-256。

本项目没有商业代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。该提示是无签名开源软件的预期行为，不代表文件一定有恶意。

发布源码以 `v2.0.2` 标签为准，所有附件均由该标签对应源码构建。
