# 安装与部署

话匣子（Huaxiazi）面向 Windows 10/11 x64，提供两种交付形态。两种形态跑的是**同一份自包含文件夹发布**，差别只在"怎么送到用户机器上"；**用户数据目录默认在 C 盘**。

## 一、两种交付形态

| 形态 | 交付文件 | 适用场景 | 安装路径 |
|------|----------|----------|----------|
| **安装包**（推荐） | `Huaxiazi-Setup.exe` | 普通用户，双击 Inno Setup 向导安装 | 默认当前用户 C 盘目录；也支持 `/DIR=` 指定 |
| **免安装** | `Huaxiazi-Portable.zip` | 便携、U 盘、多机试用 | 解压后直接运行其中的 `Huaxiazi.exe` |

> 交付物不附带脚本安装器。安装包的 `.bin` 文件是 Inno Setup 的安装数据分片，不是辅助代码；安装包和便携包都包含完整的自包含运行目录，
> 因此不需要 .NET、PowerShell 7 或其他额外运行时。

## 二、安装路径怎么指定

### 1. Inno Setup 安装包

将 `Huaxiazi-Setup.exe` 与同目录下的 `Huaxiazi-Setup-*.bin` 放在一起，双击 `Huaxiazi-Setup.exe`，使用完整 Inno Setup 向导安装。默认写入**仅当前用户**的 `%LocalAppData%\Programs\话匣子`，不需要管理员权限。
需要指定安装路径时使用下面的 `/DIR=` 参数；目标目录必须对当前用户可写。如果明确选择 `Program Files`，需要以管理员身份启动安装器。

### 2. 静默安装（批量/脚本）

```powershell
# 指定路径（目标目录需对当前用户可写）
.\Huaxiazi-Setup.exe /VERYSILENT /DIR="D:\Apps\Huaxiazi" /NORESTART

# 如需 Program Files，请先以管理员身份启动终端再执行
.\Huaxiazi-Setup.exe /VERYSILENT /DIR="C:\Program Files\话匣子" /NORESTART
```

卸载：Windows「设置 → 应用 → 话匣子」，或运行安装目录下的 `unins000.exe`；用户数据目录不会被删除。

### 3. 免安装

解压 `Huaxiazi-Portable.zip` 后直接运行其中的 `Huaxiazi.exe` 即可，无需安装、无需另装 .NET。

## 三、数据目录：默认固定在 C 盘

**程序装到哪个盘与数据放在哪里无关**，默认数据目录恒为：

```text
%LocalAppData%\Huaxiazi        即 C:\Users\<用户名>\AppData\Local\Huaxiazi
```

即使把程序安装到 `D:\Apps\Huaxiazi`，数据仍然写在 C 盘用户目录。实现依据：

- `App.DefaultDataRoot` 取 `Environment.SpecialFolder.LocalApplicationData` + `Huaxiazi`；
- `Config/default-config.json` 中 `dataDirectory` 默认为空字符串；
- `DataDirectoryPolicy.ResolveOrDefault(settings.DataDirectory, DefaultDataRoot)` 在未配置时回落到默认根。

目录内容：

```text
config.json          非敏感配置
secrets\             DPAPI 加密的 API Key
data\huaxiazi.db     SQLite 索引与版本关系
data\drafts\        最终成稿 .txt
data\trash\         软删除回收站
errors.log           错误日志
```

需要改位置时：**设置 → 数据管理 → 数据目录**（保存后重启生效）。
卸载程序**不会**删除该目录，用户资料与密钥都会保留。

## 四、构建（发布者）

```powershell
cd PromptFloat

# 正式发布：产出 Inno Setup 安装包 + 免安装 ZIP
.\publish.ps1 -AllowUnsigned -Clean -RequireInstaller

# 本地调试时跳过单元测试（正式发布不要加）
.\publish.ps1 -AllowUnsigned -Clean -SkipTests
```

前置条件：

- **.NET 8 SDK**（`dotnet --version` 应有输出）；
- **联网**：自包含发布需要还原 `win-x64` 运行时包（`NuGetLockFilePath=deploy/packages.win-x64.lock.json`）；
- **Inno Setup 6.7.3+**：发布脚本自动查找 `ISCC.exe`；使用 `-RequireInstaller` 时找不到编译器会直接失败。
- 用户机器不需要安装 .NET Runtime 或 PowerShell 7。

## 五、发布后核对

```text
release\
├── Huaxiazi-Setup.exe        Inno Setup 启动程序（与下方 .bin 一起运行）
├── Huaxiazi-Setup-*.bin      Inno Setup 安装数据分片（非代码）
├── Huaxiazi-Portable.zip     便携包（解压即用）
└── SHA256SUMS.txt            上述文件的 SHA-256 校验值
```

```powershell
# 校验完整性
Get-Content .\release\SHA256SUMS.txt
Get-FileHash .\release\Huaxiazi-Setup.exe -Algorithm SHA256
```

未签名的程序首次运行可能触发 Windows SmartScreen「未知发布者」提示，需点「更多信息 → 仍要运行」；
正式分发建议配置代码签名（`publish.ps1 -CertPath / -CertSha1`）。

## 六、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `release` 里没有 `Huaxiazi-Setup.exe` | 未找到 Inno Setup，或发布尚未完成 | 安装 Inno Setup 6.7.3+ 后重跑；使用 `-RequireInstaller` 可确保缺失时直接失败 |
| 启动时仍提示无法创建 `is-*.tmp` | 使用了旧的单文件 Inno 安装包 | 确认下载的是完整交付目录，包含 `Huaxiazi-Setup.exe` 和 `Huaxiazi-Setup-*.bin`；当前版本使用 `UseSetupLdr=no`，不再依赖 `is-*.tmp` |
| SmartScreen 显示“Windows 已保护你的电脑” | 未签名文件或文件带有下载来源标记 | 正式发布配置代码签名；临时测试可在文件属性中勾选“解除锁定”，或点击“更多信息 → 仍要运行” |
| 发布在 restore 阶段失败 | 无网络，或 `deploy/packages.win-x64.lock.json` 与依赖不一致 | 联网后重试；依赖变更时先更新锁文件 |
| 便携包双击没反应/没窗口 | 未完整解压 ZIP，或把 EXE 单独拷出导致缺少 `Resources/`、`Prompts/` 等随包目录 | 重新完整解压 `Huaxiazi-Portable.zip`，再运行其中的 `Huaxiazi.exe` |
| 安装到 D 盘后找不到数据 | 数据不在安装目录 | 见本文第三节，数据在 `%LocalAppData%\Huaxiazi` |
