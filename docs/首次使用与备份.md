# 首次使用、备份与恢复

## 首次配置

1. 打开“设置 → 模型与 API”，选择或新建 Provider 配置。
2. 选择推荐模型，确认最终 Model ID；本地 Ollama/LM Studio 配置不需要 API Key。
3. 云端配置粘贴用户自己的 API Key，点击“验证并保存”。离线时可选择先保存、稍后验证。
4. 首次生成前确认正文和明确填写的背景会发送到当前选择的模型服务商。

密钥只显示“已安全保存”，不会回显原文；移除密钥必须显式保存。配置和密钥均按 Provider 独立管理。

## 备份与恢复

退出应用后备份整个目录：

```text
%LocalAppData%\Huaxiazi
```

恢复时保持应用退出，将目录复制回原位置。DPAPI 密钥绑定原 Windows 用户和设备环境，跨设备恢复后通常需要重新填写 API Key。备份前应确认其中包含本地明文历史和草稿。

卸载或升级不会自动删除用户数据。永久清理前先导出需要保留的成稿；清空操作不可撤销。
