# 首次使用、备份与恢复

1. 打开“设置 → 模型与 API”。左侧“我的配置”用于选择、添加、复制和删除配置。
2. 在右侧直接点击常用厂商卡片；更多平台、本地模型和自定义接口位于展开项中。
3. 云端平台粘贴自己的 API Key，再选择推荐模型；最终 Model ID 会明确显示，也可直接修改。官方 API 地址会自动配置。
4. 点击“验证并保存”。连接成功后配置立即启用；离线时可选择“仍然保存，稍后验证”。
5. Ollama、LM Studio 等本地模型不需要 API Key；自定义兼容接口可在“高级设置”中填写地址。
6. 首次使用云端模型前，请确认你接受正文和所填背景发送给该服务商。

已保存的密钥不会重新显示在输入框中，界面只提示“已安全保存”。“移除密钥”在保存后生效；取消设置不会修改磁盘中的密钥。

备份时先退出话匣子，再复制整个 `%LocalAppData%\Huaxiazi` 文件夹。恢复时在退出应用的状态下将备份复制回相同位置。DPAPI 密钥通常只能由原 Windows 用户在原用户配置环境中解密；迁移到另一台电脑后应重新填写 API Key。

卸载或升级不会删除 `%LocalAppData%\Huaxiazi`。永久清空资料库不可撤销，建议先在“数据管理”中导出需要保留的成稿。
