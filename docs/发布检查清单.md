# 发布检查清单

- `dotnet restore Huaxiazi.sln`
- `dotnet build Huaxiazi.sln -c Release --no-restore`，要求 0 警告、0 错误
- `dotnet test PromptFloat.Tests/PromptFloat.Tests.csproj -c Release --no-build`，要求全量通过
- `.\publish.ps1 -Clean`（输出统一进入 `out/`）
- 生成便携 ZIP 和 Inno Setup 安装包
- 计算安装包 SHA-256，填入 `update-manifest.template.json`
- 有证书时签名并验证 Authenticode；无证书时明确标为测试版
- 在干净 Windows 10/11 x64 验证全新安装、升级、离线启动和卸载保留资料
- 在 100%、125%、150%、175%、200% DPI 逐项截图，并做混合缩放跨屏验证
