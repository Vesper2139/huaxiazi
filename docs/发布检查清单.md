# 发布检查清单

- 使用 .NET SDK `8.0.424`（自包含运行时 `8.0.30`）
- Release 输出的 runtimeconfig 必须保持 `System.Runtime.Serialization.EnableUnsafeBinaryFormatterSerialization=false`
- `dotnet restore Huaxiazi.sln --locked-mode`
- `dotnet list Huaxiazi.csproj package --vulnerable --include-transitive`，测试工程同样执行，要求无已知漏洞
- `dotnet build Huaxiazi.sln -c Release --no-restore`，要求 0 警告、0 错误
- `dotnet test Huaxiazi.Tests/Huaxiazi.Tests.csproj -c Release --no-build`，要求全量通过
- 使用 PowerShell 7（`pwsh`）运行 `./publish.ps1 -Clean -CertPath <PFX> -CertPassword <密码> -UpdateManifestPublicKey <Base64-SPKI>`；缺少签名材料必须失败
- 生成便携 ZIP 和 Inno Setup 安装包
- 计算已签名安装包 SHA-256，调用 `deploy/generate-manifest.ps1 -SigningKeyPath <RSA-PEM>` 生成签名清单信封
- 用 `Get-AuthenticodeSignature` 验证每个发布 PE 为 `Valid`，并核对签名证书 SHA-256 与应用内固定值完全一致
- PFX 仅写入 `$RUNNER_TEMP`，签名后立即删除；任何 artifact 目录不得出现 `.pfx/.pem/.key`
- GitHub Actions 必须配置 `PFX_BASE64`、`PFX_PASSWORD`、`SIGNER_CERTIFICATE_SHA256`、`UPDATE_MANIFEST_PUBLIC_KEY`；缺一项禁止上传 artifact
- Inno Setup 使用当前受支持版本（至少 6.7.3；推荐 7.1.0 x64），正式安装到受保护的 Program Files
- 备用 `deploy/install.ps1` 同样要求管理员权限，并将目标限制在 `%ProgramFiles%\Huaxiazi` 下；不要把用户可写目录作为生产安装路径
- 在干净 Windows 10/11 x64 验证全新安装、升级、离线启动和卸载保留资料
- 在 100%、125%、150%、175%、200% DPI 逐项截图，并做混合缩放跨屏验证
