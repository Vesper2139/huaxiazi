# 发布检查清单

## 构建与测试

- 使用锁定依赖恢复：`dotnet restore Huaxiazi.sln --locked-mode`
- Release 构建零警告、零错误；核心测试与 WPF 敏感测试全部通过。
- 依赖漏洞审计无阻断项；禁止提交 `bin/`、`obj/`、本地配置、数据库和展开发布目录。
- 运行时配置保持 `System.Runtime.Serialization.EnableUnsafeBinaryFormatterSerialization=false`。

## 发布物

- 使用 `pwsh .\publish.ps1 -AllowUnsigned -Clean` 生成自包含 Windows x64 发布物。
- 生成 `Huaxiazi.exe`、`Huaxiazi-Portable.zip` 和 `SHA256SUMS.txt`；安装包仅在 Inno Setup 可用时生成。
- 下载 Release 附件后重新计算 SHA-256 并逐项核对。
- 未签名版本必须在 Release 中披露 SmartScreen/未知发布者提示；如未来签名，PFX 只允许存在于临时目录。

## 发布后验证

- 干净 Windows 10/11 x64 验证首次启动、离线启动、升级、卸载和数据保留。
- 检查 100%–200% DPI、主题、快捷键、模型切换、无痕模式和 API Key 脱敏。
- CI 通过后再创建版本标签与 GitHub Release。
