# Agent 架构项目报告

## 结论

话匣子已形成面向中文表达处理的本地 Agent 编排骨架：规划、Skill 路由、分层上下文、Provider 适配、结构化解析、质量门禁和本地归档均由代码控制。模型负责生成候选结果，事实、权限、重试和副作用由应用裁决。

## 交付范围

| 层 | 交付内容 |
| --- | --- |
| 决策 | 场景分析、风险分级、模型档位建议、有限澄清 |
| 策略 | Skill 过滤、最多三项组合、冲突回退、低优先级投影 |
| 上下文 | 固定层级、字符预算、必需层保护、注入清洗、trace |
| 执行 | Polish / PromptOptimize 两条工作流，Provider 错误归一化 |
| 治理 | 事实锚点、结构化输出、有限修复、幂等、超时、日志脱敏 |

## 当前限制

工具 Harness 是受控扩展边界，默认中文表达工作流不开放任意机器权限；真实向量数据库、多模态管道、跨 Provider 流式工具协议和大规模模型消融仍需单独集成验证。

## 发布判定

只有通过单元测试、WPF 敏感测试、依赖审计、发布构建和干净环境验证的能力，才能写入生产能力清单。历史实验记录仅用于追溯，不覆盖当前运行时事实。

详细模块、状态模型和调用规则见 [Agent 架构与工程编排](AGENT_ARCHITECTURE.md)。
