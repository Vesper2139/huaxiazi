# 隐私与数据

话匣子默认不启用遥测、账号、云同步或剪贴板读取。正文、背景、模型响应和 API Key 不写入诊断日志。

表达润色或提示词优化请求只会发送到用户当前选择的模型配置档。云端模型会收到本次正文、用户明确填写的背景、输出风格及长期指令；本地 Ollama 请求仅发送到配置的本地地址。

API Key 由 Windows DPAPI 以当前 Windows 用户身份加密。非敏感设置保存在 `%LocalAppData%\Huaxiazi\config.json`，资料库及成稿保存在同目录的 `data` 子目录。

启用历史且勾选“保存原文/保存优化稿”时，相应正文会以明文保存在当前 Windows 用户的本地 SQLite 数据库和成稿文件中。无痕模式不会恢复或写入工作区草稿，也不会保存历史；历史保留天数会清理超过期限的正常记录，最近删除的内容仍按删除时间保留以便恢复。卸载程序不会自动删除 `%LocalAppData%\Huaxiazi`，需要彻底清除时请在应用的数据管理页执行清理，或退出应用后手动删除该目录。

连接诊断只包含平台、模型地址的主机部分、协议、模型、HTTP 状态、耗时和服务商 Request ID。诊断与日志不得包含正文、背景、请求体、完整响应、请求头、URL 查询参数或密钥。

切换供应商时，旧供应商密钥不会用于测试新供应商。多配置的待保存密钥分别暂存在当前设置窗口内；保存失败会恢复本轮修改前的密钥状态。
