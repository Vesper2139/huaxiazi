# 隐私与数据

## 默认边界

话匣子是单机、本地优先应用：默认无账号、无遥测、无云同步、不读取剪贴板，也不提供自营 AI 后端。只有用户主动发起生成时，正文和明确填写的背景才会发送到当前选择的模型服务商。

## 密钥与配置

- API Key 使用 Windows DPAPI，绑定当前 Windows 用户保存。
- 非敏感配置位于 `%LocalAppData%\Huaxiazi\config.json`。
- 密钥不进入 Prompt、日志、诊断、仓库或发布包。
- 连接诊断只保留平台、主机、协议、模型、状态、耗时和 Request ID 等摘要。

## 本地内容

启用历史后，原文、背景和成稿默认以明文保存在本机 SQLite 与文本文件中；无痕模式不恢复或写入草稿和历史。软删除内容按回收站生命周期保留，卸载不会删除 `%LocalAppData%\Huaxiazi`。

## Provider 边界

云端 Provider 会接收本次请求正文、明确填写的背景及必要的输出约束；本地 Provider 仅访问用户配置的本地地址。切换 Provider 不会复用旧 Provider 的密钥进行测试。

完整架构与上下文边界见 [Agent 架构与工程编排](AGENT_ARCHITECTURE.md)。
