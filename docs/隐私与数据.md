# 隐私与数据

## 默认边界

话匣子是单机、本地优先应用：默认无账号、无外发遥测、无云同步、不读取剪贴板，也不提供自营 AI 后端。只有用户主动发起生成时，正文和明确填写的背景才会发送到当前选择的模型服务商。

用户可以在“历史与留存”中主动开启本机生成诊断。此项默认关闭。请求明细保存在 `diagnostics/generation-diagnostics.jsonl`，工作流摘要保存在 `diagnostics/generation-workflow-diagnostics.jsonl`；两类记录用随机生成 ID 关联。明细包含任务、平台/协议、实际模型标识、时延、可用 Token 用量、HTTP 状态、规范化结果类别、Request ID，以及受管本地运行时报告的实际 CPU/Vulkan 后端、首次请求关联的启动到就绪时间、启动后首个/后续请求标记和进程峰值工作集。汇总报告按任务/Provider/模型/实际后端计算时延分位数、可用 Token 总量、质量门禁、启动耗时分位数、首个/后续本地请求的时延统计、观测到的最大工作集及本地输出 Token/请求时间估算速率；请求阶段来自 runtime 实际请求序号，不从时延猜测。该速率包含 loopback API 开销，不等于模型纯解码速度，工作集不代表显存。设置页可生成 `diagnostics/generation-diagnostics-summary.json`；缺失用量不会被当成 0，未绑定费率卡时不估算费用。数据不上传，也不记录请求正文、模型成稿、背景、偏好、校验消息、密钥、配置名称、服务地址或设备硬件标识。无痕模式强制关闭记录。设置页可一键清除请求明细、工作流摘要和汇总报告；每个日志文件最多保留最近 500 条。

## 密钥与配置

- API Key 使用 Windows DPAPI，绑定当前 Windows 用户保存。
- 非敏感配置位于 `%LocalAppData%\Huaxiazi\config.json`。
- 密钥不进入 Prompt、日志、诊断、仓库或发布包。
- 连接诊断只保留平台、主机、协议、模型、状态、耗时和 Request ID 等摘要。

## 本地内容

启用历史后，原文、背景和成稿默认以明文保存在本机 SQLite 与文本文件中；无痕模式不恢复或写入草稿和历史。软删除内容按回收站生命周期保留，卸载不会删除 `%LocalAppData%\Huaxiazi`。

表达设置中的“清除全部偏好”会清除并保存当前 `config.json` 中的确认偏好和本地交互统计。它不会改写用户此前手动导出的偏好 JSON 或“数据维护”创建的 ZIP 备份；ZIP 内可能含创建时的 `config.json` 快照。需要从这些副本中删除偏好时，请按保存位置手动删除对应文件。恢复 ZIP 时应用会跳过其中的 `config.json`，不会自动把旧偏好写回当前配置。

## Provider 边界

云端 Provider 会接收本次请求正文、明确填写的背景及必要的输出约束；本地 Provider 仅访问用户配置的本地地址。切换 Provider 不会复用旧 Provider 的密钥进行测试。

完整架构与上下文边界见 [Agent 架构与工程编排](AGENT_ARCHITECTURE.md)。
