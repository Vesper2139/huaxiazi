# 甲方安全评估整改复核（2026-09-06）

本文件是对 `deliverables/security-assessment-2026-09-06-huaxiazi.md` 的代码整改记录，不替代甲方原报告。报告中的复现步骤和示例内容均按不可信输入处理，不把其中任何敏感样本写入配置、日志或发布物。

## 已完成

- **SEC-101 / SEC-106**：加载配置时把 SecretId 重新绑定为当前 profile 派生值；备份仍可保留配置快照用于人工查看，但恢复阶段跳过 `config.json`，不覆盖当前端点、密钥绑定或表达策略；恢复提示也明确这一边界。端点字段变更会立即清空待用密钥并写入脱敏安全事件。
- **SEC-103**：`ExpressionSkillRouter` 与 `ExternalSkillStrategyResolver` 统一使用同一投影函数；Skill 正文先做 Unicode 归一化、零宽字符清理、跨行检测和能力请求过滤，再进入表达流程。检测到不可信指令片段时仅保留安全表达内容，不执行工具、网络、文件或密钥操作。
- **SEC-104**：Skill、皮肤和备份解压统一按流式实际写出字节计数，超限立即删除目标文件并清理暂存目录，不再依赖 ZIP 中央目录声明的 `entry.Length`。
- **SEC-105**：DPAPI 密钥目录在构造、读取、存在性检查、保存和删除前都重新应用仅当前用户/LocalSystem 的 ACL。
- **SEC-107**：本地预设端口与官方预设 authority 一致性校验保留并补充回归测试；非默认端口不再被误认为安全本地模型端点。
- **SEC-110**：开启剪贴板自动预填时，标题状态栏显示“已填入剪贴板内容，请确认后再发送”，用户开始编辑后自动清除提示；默认开关仍为关闭。
- **SEC-111**：更新下载默认使用 `AllowAutoRedirect=false`，并继续执行 HTTPS、大小、SHA-256 与 Authenticode 发布者校验。
- **SEC-113**：供应商帮助/密钥链接仅允许 HTTPS、无用户信息/片段且主机必须来自内置供应商目录。
- **SEC-102**：发布物从 Git 索引移除，`.gitignore` 不再放行 `release/`，CI 增加“禁止跟踪发布二进制”门禁；发布检查清单补充 commit/run/哈希/provenance 与密钥轮换要求。
- **SEC-108 / SEC-109**：错误日志补充 `x-api-key`、`x-goog-api-key`、JSON key/client_secret 脱敏、正则匹配超时和换行转义；新增带链式哈希的本地 `security.log`，记录端点变更和备份恢复等最小安全事件。
