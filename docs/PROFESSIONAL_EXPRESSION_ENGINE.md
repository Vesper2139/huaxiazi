# Vesper 专业表达引擎

Vesper v1.5.0 只解决一个核心问题：在不改变事实、立场与承诺的前提下，把零散或口语化输入转换为可直接使用的专业表达或专业提示词。

## 执行边界

两种模式共用“上下文解析 → 专业化计划 → 表达策略 → 生成 → 本地质量检查 → 最多一次修复”的流水线。人物、数字、日期、否定、条件与不确定程度属于高优先级事实锚点；任何表达策略都不能覆盖这些约束。

## 离线预置能力

- GitHub `prompt-optimizer`：提示词优化。
- Anthropic `internal-comms`：职场沟通、汇报和项目更新。
- GitHub `documentation-writer`：技术教程、说明和参考文档。

三项均以固定上游提交和许可证快照随安装包离线分发。`ExpressionSkillRouter` 根据模式、场景和输入关键词每次最多选择一项；无匹配项时回到 Vesper 的事实安全基线。

## 外部 Agent Skills

高级设置支持导入本地 `SKILL.md`、Skill 目录或 ZIP。导入后复制快照到 `%LocalAppData%\Huaxiazi\agent-skills`，不链接源目录。Vesper 首版只读取包内受支持的文本参考，不执行脚本、Shell、Python、MCP 或浏览器操作，也不会向 Skill 暴露密钥、历史正文和诊断。

外部策略始终低于事实保真、用户本次明确要求、安全边界与输出协议。设置中的单项开关是唯一可用状态，不存在另一个隐藏的当前策略选择。

## 本地偏好

偏好学习只保存长度、结构、场景使用次数和被删除套话的计数，不保存生成稿或用户编辑稿副本。无痕模式暂停学习，用户可在“表达能力”的个性化区域关闭或重置。

## 旧版知识数据

v1.5.0 不再打开、检索或注入旧知识数据库。若检测到 `%LocalAppData%\Huaxiazi\knowledge\knowledge.db`，数据管理页仅提供显式导出和永久删除；升级本身不会移动或删除该文件。
