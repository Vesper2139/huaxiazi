# 专业表达引擎

话匣子只解决一个问题：在不改变事实、立场和承诺的前提下，将零散中文转换为可直接使用的成稿或专业提示词。

## 运行链路

```text
输入 → 场景与事实解析 → 专业化计划 → Skill 路由 → LLM 生成
     → 协议解析 → 质量门禁 → 必要时一次修复 → 本地归档
```

事实锚点包括人物、数字、日期、否定、条件和不确定程度，优先级高于任何表达策略。

## Skill 边界

预置能力以固定快照随安装包离线分发。`ExpressionSkillRouter` 按模式、场景和关键词选择最多三个高置信 Skill；冲突时回退主 Skill。外部 Skill 仅作为低优先级文本策略导入，不执行脚本、Shell、Python、MCP、浏览器或任意文件访问。

## 数据边界

偏好仅保存结构化统计，不保存模型稿与用户稿样本。API Key、历史正文和诊断信息不会注入 Skill 或日志。完整架构见 [Agent 架构与工程编排](AGENT_ARCHITECTURE.md)。
