# 产品功能体系与实施路线

## 产品边界

话匣子是本地优先的中文表达工作台，当前生产能力集中在两条工作流：表达润色和提示词优化。每项能力必须同时具备入口、状态反馈、错误处理、数据恢复和关键测试，才视为完成。

## 当前能力

| 领域 | 当前实现 |
| --- | --- |
| 工作区 | 输入、双模式、草稿恢复、生成/停止、结果编辑、复制与 Diff |
| Agent 编排 | 规划、Skill 路由、分层上下文、模型档位建议、质量门禁 |
| Provider | OpenAI-Compatible、Anthropic、Gemini、本地 Ollama/LM Studio |
| 数据 | SQLite 历史、文本成稿、搜索、软删除、恢复、导出与清理 |
| 隐私 | DPAPI 密钥、无痕模式、诊断脱敏、本地/云端去向提示 |
| 桌面体验 | WPF 浮窗、托盘、快捷键、高 DPI、主题和多配置 |

## 后续路线

1. **数据与隐私闭环**：历史筛选、保留策略、备份恢复、无痕会话和一键清理。
2. **生产力工作流**：预设管理、快捷键自定义、剪贴板策略和模型能力声明。
3. **桌面韧性**：多屏高 DPI、更新说明、安装回滚和数据迁移验收。
4. **Agent 扩展**：在权限、幂等、回放和回归测试齐备后接入受控工具与知识源。

## 验收标准

功能必须有真实入口、可观察状态、可恢复错误、明确数据生命周期、自动化测试和干净环境验证。实验能力或未接入 Provider 不得写入“当前生产能力”。
