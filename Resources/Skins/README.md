# 内置皮肤素材来源与许可边界

代码和应用逻辑按仓库根目录许可证发布；该许可证**不自动覆盖**本目录及 `Resources/Brand/Skins/` 中的角色图像、图标和其他美术资源。

项目负责人确认：新增素材来自开源社区或 GPT 图像生成，并可按公开项目内容发布。逐素材的上游 URL、作者、原始许可证、生成提示与版本记录尚未完整登记。因此，使用者应将每套图片视为独立素材，发布或再分发前核对对应来源条款；本仓库不能据此 README 为每项素材授予额外版权。

新增或替换素材时，应在本目录维护来源清单，记录皮肤 ID、文件清单、来源 URL/生成工具、作者或生成责任方、许可证/服务条款、获取日期及 SHA-256。不得把第三方素材默认为 MIT。

皮肤技术目录与文件格式见 [`../../docs/skin-system.md`](../../docs/skin-system.md)。
